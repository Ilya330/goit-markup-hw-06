# goit-markup-hw-06

Адаптивна сторінка WebStudio: Mobile First від 320px, tablet від 768px, desktop від 1158px.

Запуск через Live Server у VS Code або:

```sh
python3 -m http.server 8000
```

Відкрийте http://localhost:8000. Меню і форма відкриваються кнопками, закриваються хрестиком або Escape. Фокус утримується у відкритому вікні; повернення до сторінки відновлює фокус на кнопці.

`css/main.css` імпортує окремі стилі секцій, `modal.css` та `mobile-menu.css`. Контентні зображення використовують `srcset`, фони Hero — `image-set()`.

## Залишкова перевірка Retina-ресурсів

Надані фото Team та mobile/tablet-фони мають правильні пари 1x/2x. Desktop-файл `people-office@2x.jpg` має 1536×872 замість 2880×1200; шість фото Portfolio @2x мають 712×600 замість 720×600. Вони підключені без штучного збільшення; для повної відповідності потрібні правильні експорти з Figma.
